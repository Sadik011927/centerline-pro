100% Free Domain + HTTPS + Direct Folder Auto-Save

  1. GitHub অ্যাকাউন্টে লগইন করুন (github.com) এবং নতুন একটি Public Repository তৈরি করুন (যেমন: centerline-pro)।
  2. এই ডাউনলোড করা index.html ফাইলটি ওই রিপোজিটরিতে Add file → Upload files দিয়ে আপলোড করে Commit changes করুন।
  3. রিপোজিটরির Settings → Pages মেনুতে যান, Branch হিসেবে main এবং ফোল্ডার / (root) সিলেক্ট করে Save ক্লিক করুন।
  4. ১ মিনিটের মধ্যে আপনার স্থায়ী ফ্রি ওয়েবসাইট লিংক চালু হয়ে যাবে: https://yourname.github.io/centerline-pro/
